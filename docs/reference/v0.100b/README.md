# Historical v0.100b references

These text captures were imported unchanged from `srp-survarium/gists`,
commit `43b51e22bec6dfb9762bf8d2512718887bb93cfb` (2025-08-12), before
retiring that repository.

- [console_commands.txt](console_commands.txt): 324 console-command entries
  (323 unique names), including the original lazy-registration annotations.
- [exe_options.txt](exe_options.txt): captured executable help output with 66
  primary launch options. Its banner identifies build 802, dated 2013-05-11.
- [engine_files.txt](engine_files.txt): 3,015 original engine source paths.
  This is a historical file list, not a checklist of files required in the
  current reconstruction.

These are reference snapshots. Consult the reconstructed source for command
implementations and option definitions; every listed command and primary
option name was present in `sources/vostok/` when these files were imported.

The old `engine_structure.txt` dump was not imported. The original retail PDB
and the current PDB tools provide the function, address, and source-line
information; see [target versus base](../../target-vs-base.md) and
[PDB topology](../../binary_matching/pdb_topology.md).
